Privacy & control

Local by intent. Open by default.

Privacy is an architecture decision, not a marketing line. The goal is a keyboard that works without an account, keeps your typing on your device, and makes every network request something you chose.

On-device first

Typing, language models, and suggestions are intended to run on your phone. Network use should be the exception, not the default.

You approve AI requests

AI-powered actions should be explicit, visible, and cancellable. No silent background requests, and no hidden data trails.

Secure credentials

API keys and tokens are intended to live in Android’s Keystore-backed storage — never in plain text, never on a server we control.

Open to inspection

The source will be public. Claims about privacy and security should be verifiable by anyone, not taken on faith.

Macaw Board is still in development. These are design intentions, not audited guarantees. The final security and data-flow model will be documented before release, with limitations stated plainly.
